# 🎬 每日电影

> 一个基于 IMDb Top 250 与豆瓣电影 Top 250 合并去重后的随机电影抽取工具。

## 在线体验

GitHub Pages 自动部署，访问地址：
```
https://你的用户名.github.io/daily-movie/
```

## 功能

- 🎲 **随机抽取**：老虎机滚动效果，一键抽取今日电影
- 🏷️ **来源筛选**：全部 / 仅 IMDb / 仅豆瓣 / 双榜重合
- 📊 **数据统计**：实时显示各榜单收录数量
- 📜 **抽取记录**：自动保存最近 10 次抽取结果
- 🎬 **影片信息**：中文名、原名、年份、评分、类型、国家、导演、简介

## 数据来源

- **IMDb Top 250**：全球影迷评分最高的 250 部电影
- **豆瓣电影 Top 250**：中文世界最具影响力的电影榜单
- 两个榜单合并去重后精选约 150 部核心影片

## 本地使用

无需安装，直接双击 `index.html` 即可在浏览器中运行，完全离线可用。

## 部署到 GitHub Pages

1. Fork 本仓库
2. 进入仓库 Settings → Pages
3. Source 选择 "Deploy from a branch"
4. Branch 选择 `main`，文件夹选择 `/ (root)`
5. 点击 Save，等待 1-2 分钟即可访问

## 技术栈

纯前端实现：HTML + CSS + JavaScript，无后端依赖，无外部资源加载。
